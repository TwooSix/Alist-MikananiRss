# Openlist-Ani Wiki

🎬 RSS 订阅 → 自动下载 → AI 重命名，一站式番剧自动化管理

从动漫番剧相关的 RSS 订阅源中自动获取番剧更新，通过 Openlist 离线下载至对应网盘，并结合 LLM 分析资源名，将资源重命名为 Emby / Jellyfin 可解析的格式。

## ✨ 特点

- 📡 **自动追番** — 自动获取 RSS 番剧更新并下载
- 📦 **多网盘支持** — 基于 OpenList 实现，支持 PikPak、115 等离线下载
- 🗂️ **合集整理** — 一次下载多集文件，逐集解析元数据、匹配字幕并归类到媒体库
- 🤖 **AI 重命名** — AI 分析资源名 + TMDB 搜索，精准获取番剧名、季度、集数
- 💬 **智能助理** — 挂载至 Telegram Bot，通过自然语言让 AI 帮你搜索并下载资源
- 🔔 **更新通知** — 通过 PushPlus、Telegram 等渠道推送更新
